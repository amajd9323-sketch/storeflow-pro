حسابي Pro 3.3.0
================

نظام إدارة متجر عربي RTL، يعمل عبر الويب/PWA وعلى Android.

تحديث الهاتف:
- قائمة "كل الميزات" تعرض أقسام نسخة الكمبيوتر الـ 11 كاملة.
- إجراءات البيع والشراء والمخزون والعملاء والموردين والدفعات والمصاريف متاحة من القائمة.
- تصدير CSV للمبيعات والمشتريات والمخزون والعملاء والمصاريف.
- استيراد وتصدير النسخ الاحتياطية من الهاتف.
- الجداول أصبحت قابلة للتمرير أفقيًا مع بقاء عناوين الأعمدة ظاهرة.
- النوافذ المنبثقة ملائمة لشاشات الهاتف ولوحة المفاتيح.

بناء APK:
1. ثبّت Node.js 20 أو أحدث وJava 17 وAndroid SDK.
2. نفّذ: npm install
3. نفّذ: npm run check
4. نفّذ: npm run android:prepare
5. نفّذ: cd android && ./gradlew assembleDebug
6. الملف الناتج: android/app/build/outputs/apk/debug/app-debug.apk

GitHub Actions:
- كل تحديث على main يجهز Debug APK تلقائيًا.
- يحفظ APK كـ Actions artifact وينشئ GitHub Release قابلًا للتنزيل.
- الملف المنشور Debug-signed للاختبار والتثبيت المباشر؛ توقيع إصدار إنتاج ثابت يتطلب Keystore خاصًا محفوظًا في GitHub Secrets.

معرّف Android: com.hesabi.pro
نسخة التطبيق: 3.3.0
